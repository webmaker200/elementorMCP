# Salus AI page — build notes

- Page: WP page **410964** `/salus-ai/` (Elementor V4 atomic), Figma `oYqLJMmgAjdLKQeLgtDSM7` node **626:2408**.
- Builder: `tools/salus.py` (8 sections, page-local styles from Figma values). Deploy: `build_salus.py` (draft → build → assert structure → publish) then `verify_salus.py --touch` (forces CSS regeneration, checks every style class is in the local CSS).
- Backgrounds: Figma's blurred ellipses bleed across sections (clipsContent=false). `tools/bg.py` re-renders all LAYER_BLUR ellipses in document order (sigma = blur/2), `tools/slice.py` cuts one WebP per section at the content gaps (97/963/2206/3227/4634/5466/6826/7861/8926 px). Each slice is the section's native Elementor background image with size `100% 100%`, so neighbouring slices meet seamlessly at any width.
- Site gotchas found here: theme CSS has `p{margin-block-end:0 !important}` → paragraph spacing is expressed as padding / next-sibling margin (`pfix()`); e-flexbox defaults to full width → `width:max-content` on pills/buttons; section anchor via `attributes: [{key:'id', value:'pricing'}]`; inline `<span>` attributes are stripped, but native nested CSS (`& span{}`) in a local style works.
- "See It Work" mockup (626:3455) is built natively (cards, paragraphs, code chips); its waveform/icons are SVGs generated from Figma vector geometry by `tools/mksvg.py`.
- Media ids: `media.json`. The hero dashboard (626:2734) is a 0.75× crop of the Figma page render because the Figma image-export endpoint was rate-limited (Starter plan, retry-after ≈ 25 h); re-export it at 2× and swap the attachment id when the limit resets.
